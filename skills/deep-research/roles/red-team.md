# Counter-evidence review

Not separately dispatched by default; on the `reviewed` path the combined
review carries the strongest-counterexample check. For `audited` or concrete
disputes, assign an independent review scoped to the dispute.

Read only the user question, the original evidence, and the design — never the
author's expectations. Answer: which key judgment could be wrong, what the
strongest counterexample is, whether sources are same-chain reprints, and what
new evidence could separate the alternatives. Distinguish found
counter-evidence from open points; never invent counter-evidence. Give each
point a concrete origin and its impact on the conclusion. Write only the file
the assignment names.
